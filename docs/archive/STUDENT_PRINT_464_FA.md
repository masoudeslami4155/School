# نسخهٔ ۴.۶۴ — ادغام تنظیمات چاپ پروندهٔ دانش‌آموزان

این نسخه بر پایهٔ بستهٔ فقط‌کدِ **۴.۶۳** ساخته شده و ۱۳ فایل ارسالی کاربر برای تنظیمات چاپ پرونده را ادغام می‌کند. امکانات آمار ۴.۶۳ حفظ شده‌اند. هیچ دیتابیس واقعی، کلید نشست، رمز، پشتیبان یا عکس دانش‌آموز در بستهٔ انتشار نیست.

## قابلیت‌ها

- پنل تاشوی تنظیمات چاپ در داشبورد و صفحهٔ پرونده؛ پنل باز در صفحات چاپ.
- تنظیم جهت A4 عمودی/افقی و اندازهٔ قلم بین ۵ تا ۱۸ پوینت.
- انتخاب بخش‌های چاپ، از جمله بخش سفارشی؛ اطلاعات هویتی اجباری است.
- پنهان‌کردن فیلدهای خالی و بخش‌های کاملاً خالی؛ صفر و «خیر» مقدار ثبت‌شده هستند. ستون‌های جدول برای حفظ ساختار حذف نمی‌شوند.
- تنظیمات مستقل هر حساب؛ چاپ تکی، انتخاب‌شده و فیلترشده از همان تنظیمات استفاده می‌کنند.
- پیش‌نمایش زنده در صفحهٔ چاپ و قالب مشترک پرونده برای جلوگیری از اختلاف چاپ تکی/گروهی.
- منابع قلم و CSS محلی؛ تنظیمات ظاهری به معنی اعطای مجوز دیدن اطلاعات نیستند.

## شیوهٔ استفاده

۱. در داشبورد یا صفحهٔ پرونده، «تنظیمات چاپ پرونده · A4» را باز کنید.
۲. گزینه‌ها را انتخاب و **«ذخیرهٔ تنظیمات برای حساب من»** را بزنید. در این دو صفحه، تغییرات قبل از ذخیره به پنجرهٔ چاپ بعدی منتقل نمی‌شوند؛ پیام رابط این موضوع را صریح می‌گوید.
۳. صفحهٔ چاپ تکی یا گروهی را باز کنید. در صفحهٔ چاپ، تغییر گزینه‌ها فوراً روی همان پیش‌نمایش اثر دارد؛ برای چاپ همان بار نیازی به ذخیره نیست. برای استفاده در دفعات بعد ذخیره کنید.
۴. دکمهٔ «چاپ بخش‌های انتخاب‌شده» را بزنید و در مرورگر چاپگر یا Save as PDF را انتخاب کنید. اندازهٔ کاغذ چاپگر A4 باشد؛ سربرگ/پابرگ اضافی خود مرورگر را در صورت نیاز خاموش کنید.

هنگام ذخیره، کنترل‌های مرتبط موقتاً غیرفعال می‌شوند؛ بعد از پاسخ سرور مقادیر نهایی با رابط همگام می‌شوند. در شکست ذخیره، کنترل‌ها آزاد و پیام خطا نمایش داده می‌شود؛ تغییر ذخیره‌نشده را نباید ذخیره‌شده تلقی کرد.

## اصلاحات همراه ادغام

- include پنل به `index.html` اضافه شد؛ آزمون داشبورد اکنون بدون حذف assertion موفق است.
- آرایه/شیء/عدد/مقدار null برای `orientation` در API پاسخ ۴۰۰ می‌گیرد؛ sanitizer مشترک نیز در برابر نوع غیرمتنی مقاوم شد. رفتار قبلیِ بازگشت رشتهٔ نامعتبر به پیش‌فرض حفظ شده است.
- پیش‌فرض قلم **آمار ۱۰ پوینت** باقی ماند و rollback ناخواسته به ۷ حذف شد. مقدار معتبرِ ذخیره‌شدهٔ کاربر همچنان مقدم است.
- متن راهنمای تغییراتِ ذخیره‌نشده در صفحهٔ پرونده و داشبورد اصلاح شد.
- رقابت ویرایش با پاسخ درخواست ذخیره رفع و همگام‌سازی پاسخ قطعی سرور اضافه شد.
- معلم می‌تواند بخش سفارشی را برای چاپ روشن/خاموش کند، ولی همچنان فقط فیلدهای دارای `show_to_teacher` را دریافت می‌کند.
- آزمون قدیمی چاپ با قرارداد جدید «پنهان‌سازی نمایشی» هماهنگ شد؛ آزمون‌های مستقلِ نبود دادهٔ غیرمجاز در پاسخ معلم حفظ و تقویت شدند.

## امنیت و محدودیت‌ها

- مسیر جدید `POST /student-print-settings` احراز هویت، محدودیت نقش و CSRF عمومی برنامه را رعایت می‌کند؛ تنظیمات با شناسهٔ نشست همان کاربر ذخیره می‌شوند.
- فعال‌کردن یک بخش، مجوز مشاهدهٔ دادهٔ آن را ایجاد نمی‌کند. اطلاعات خصوصی خانواده و فیلدهای سفارشیِ غیرمجاز در پاسخ معلم وارد نمی‌شوند؛ محدودهٔ دانش‌آموزان معلم سمت سرور اعمال می‌شود.
- برای پیش‌نمایش زنده، بخش‌های خاموش‌شدهٔ **مجاز برای همان کاربر** در HTML باقی می‌مانند و با `hidden` پنهان می‌شوند. ذخیره/اشتراک HTML صفحه، روش حذف قطعی داده نیست. آزمون PDF تأیید کرده است که بخش‌های خاموش‌شده در PDF سناریوی آزمایشی حضور ندارند.
- پروندهٔ طولانی ممکن است چند صفحه شود. حفظ یکپارچگی بعضی بلوک‌های متن می‌تواند فضای خالی در انتهای صفحه ایجاد کند.
- چاپگر فیزیکی، تمام مرورگرها و دیتابیس واقعی مدرسه آزموده نشده‌اند؛ نتایج زیر مربوط به دادهٔ مصنوعی و Chromium هستند.

## نتیجهٔ تست سلامت

- **۲۱ اسکریپت** سمت سرور/رگرسیون: ۱۸ فایل `*_test.py` به‌علاوهٔ parser resilience، persistence و smoke مسیرها؛ همگی موفق.
- ۲۲ آزمون تخصصی آمار داخل همین مجموعه موفق بود.
- اسموک‌تست مسیرهای GET برای نقش‌های برنامه: بدون خطای ۵۰۰ یا استثنا. پاسخ‌های ۴۰۳ موردانتظارِ مجوزها خطای سلامت محسوب نمی‌شوند.
- `student_print_regression_test.py --browser`: آزمون اصلی مرورگر چاپ به‌علاوهٔ راهنمای ذخیره، انتقال تنظیم ذخیره‌شده از پرونده به چاپ، قفل کنترل‌ها حین ذخیره، همگام‌سازی پاسخ و بازیابی از خطای ۵۰۳؛ موفق.
- آزمون‌های مرورگر آمار، استودیوی چاپ، اسناد AI، عامل AI و طراحی AI؛ موفق.
- PDF آمار چندصفحه‌ای و حفظ آخرین ردیف و سربرگ‌ها؛ موفق.
- PDF پروندهٔ طولانی با ۷۰ سطر نشانه‌گذاری‌شده و ۳۲ ردیف خواهر/برادر: عمودی **۴ صفحه**، افقی **۵ صفحه** و گروهی **۴ صفحه**. تمام نشانه‌های موردانتظار در متن PDF موجود بودند؛ واژه‌های استخراج‌شده بیرون از کاغذ نبودند و صفحهٔ کاملاً خالی مشاهده نشد.
- پس از خاموش‌کردن خانواده و خواهر/برادر، PDF گروهی **۱ صفحه** شد و تمام نشانه‌های آن بخش‌ها از متن PDF غایب بودند.
- این تعداد صفحات مربوط به fixture تنش است، نه تعداد صفحات ثابت برای پرونده‌های واقعی.

### اجرای مجدد آزمون‌های اصلی این قابلیت

```bash
python -m pip install -r requirements.txt
python -m playwright install chromium
python tests/student_print_test.py
python tests/student_print_regression_test.py --browser
python tests/print_studio_routes_test.py
python tests/statistics_frequency_test.py
python tests/smoke_get_routes.py
```

برای بررسی اختیاری متن/هندسهٔ PDF:

```bash
python -m pip install pymupdf
python tests/student_print_pdf_check.py
python tests/statistics_pdf_check.py
```

در لینوکس ممکن است نصب وابستگی‌های سیستم Chromium با `python -m playwright install --with-deps chromium` لازم باشد. PyMuPDF صرفاً ابزار آزمون PDF است، نه نیاز جدید اجرای عادی برنامه. چاپ از مرورگر کاربر به نصب Playwright روی سرور نیاز ندارد؛ Playwright برای تست‌ها و خروجی PDF سمت سرور استفاده می‌شود.

## نصب و ارتقا از ۴.۶۳

۱. برنامه را ببندید و از نصب فعلی، به‌خصوص دیتابیس و پوشه‌های بارگذاری و تنظیمات خصوصی، پشتیبان بگیرید.
۲. ZIP جدید را در یک پوشهٔ موقت استخراج کنید؛ فایل‌های کد را در مسیر متناظر نصب فعلی جایگزین کنید. دیتابیس، `.secret_key`، اطلاعات ورود، uploads، backupها و فایل‌های تنظیم خصوصی موجود را حذف نکنید. اگر `config.py` یا فایل‌های کد را شخصاً سفارشی کرده‌اید، تغییرات محلی را مقایسه و حفظ کنید.
۳. وابستگی‌ها را با `python -m pip install -r requirements.txt` یا در ویندوز با `py -m pip install -r requirements.txt` نصب/به‌روز کنید.
۴. با `python app.py` / `py app.py` یا `run.bat` اجرا و مرورگر را با Ctrl+F5 تازه کنید. `run.bat` نصب خودکار وابستگی‌ها را انجام نمی‌دهد.
۵. نسخهٔ رابط باید **۴.۶۴** باشد. تنظیمات چاپ هر کاربر را در پنل خود او بررسی کنید. برای این قابلیت جدول جدید یا انتقال دستی داده لازم نیست؛ تنظیمات از مخزن تنظیمات فعلی استفاده می‌کنند.
