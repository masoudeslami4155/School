# نقشهٔ مستندات

این فایل می‌گوید کدام سند را بخوانید و مستند تازه را کجا بنویسید. پیش از این، تغییرات نسخه‌ها در چهار سند تکرار می‌شد و از هم واگرا شده بود؛ اکنون یک مرجع تغییرات وجود دارد.

|---|---|---|

## قاعدهٔ افزودن مستند

1. هر انتشار یک بخش تازه در `CHANGELOG_FA.md` می‌گیرد — در بالای فایل و جدیدترین اول.
2. برای هر نسخه فایل مستند جداگانه ساخته نشود. اگر توضیح بلند لازم بود، سند موضوعی موجود به‌روزرسانی شود یا بخش CHANGELOG به بایگانی لینک بدهد.
3. سند موضوعی (مثل همین فایل یا `PALETTE_SOURCES.md`) بر اساس موضوع به‌روز می‌شود، نه نسخه به نسخه.
4. پیوندها نسبی و از ریشهٔ پروژه نوشته شوند. `python tests/docs_consistency_test.py` وجود فایل مقصد، هم‌خوانی نسخه و قاعدهٔ «هر تغییر در یک سند» را بررسی می‌کند.
